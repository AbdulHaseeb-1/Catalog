# Photo Catalog Studio

Create simple **photo-only PDF catalogs** with Expo (React Native).

## Features

- **Photos only** — no product names, prices, or forms
- **Batch upload** — multi-select from the library (+ camera)
- **Layouts** — 1 / 2 / 3 / 4 photos per row (auto-arranges)
- **Clear borders** on every image in the PDF
- **Preview + export/share** PDF on device

## Quick start

```bash
npm install
npx expo start -c
```

Use Expo Go on a phone for best image picker + PDF share support.

## How to use

1. Create a catalog  
2. **Add photos** (batch multi-select)  
3. **Layout** → 1–4 per row  
4. **Preview** → **Export PDF** → Share
